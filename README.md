🤖 Robotic Prosthetic Hand

A vision-based robotic prosthetic hand that detects human hand gestures using Computer Vision (OpenCV) and controls a robotic hand through Arduino-driven servo motors in real time.

🚀 Features

* Real-time hand gesture recognition
* Computer Vision using OpenCV
* Arduino-based servo motor control
* Low-latency serial communication
* Modular and scalable architecture

🛠️ Tech Stack

* Programming: Python
* Libraries: OpenCV, MediaPipe, NumPy, PySerial
* Hardware: Arduino UNO, Servo Motors, USB Webcam

⚙️ Installation

git clone https://github.com/devvrat16/Robotic-Prosthetic-Hand.git
cd Robotic-Prosthetic-Hand
pip install -r requirements.txt

If requirements.txt is unavailable:

pip install opencv-python mediapipe numpy pyserial

▶️ Run

1. Connect the Arduino to your computer.
2. Upload the Arduino sketch.
3. Start the Python application:

python hand_tracking.py
